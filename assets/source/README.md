# Solla Code icon source

`solla-code-workflow-master.png` is the 1024×1024 source used by the development, preview, and
production Icon Composer projects.

The source was generated with Codex's built-in image-generation workflow using this prompt:

```text
Use case: logo-brand
Asset type: production desktop and mobile application icon master for Solla Code
Primary request: create an original textless app icon representing agentic coding workflows: a central intelligent routing core coordinating four small workflow nodes through a single elegant continuous orbital path, suggesting delegation, parallel work, handoff, and completion
Scene/backdrop: full-bleed rounded-square app icon on a deep ink-to-indigo background
Subject: one bold, simple workflow-orbit symbol centered in the icon; compact central core; four connected nodes; paths form a balanced dynamic loop without resembling a letter, brand mark, atom, brain, robot, chat bubble, or generic gear
Style/medium: polished vector-like 3D icon, geometric, minimal, premium software product branding, strong silhouette, clean at 16px
Composition/framing: centered, symmetrical-but-dynamic, generous internal padding, no elements clipped by the rounded-square boundary
Lighting/mood: restrained luminous depth, precise and capable, subtle soft inner glow only
Color palette: deep ink and indigo background; electric violet and cyan workflow paths; one small warm coral completion accent
Materials/textures: smooth satin glass and softly luminous enamel; crisp edges; no realistic scene
Constraints: no text, no letters, no T3, no S, no numbers, no logos, no watermark; exactly one icon on a perfectly square canvas; high contrast and readable when downscaled; avoid tiny details; no exterior drop shadow beyond the canvas
Avoid: typography, monograms, gradients that wash out the silhouette, excessive bloom, skeuomorphic circuitry, code brackets, terminal prompt symbols, mascots, faces, stock AI sparkles, busy network diagrams, mockup presentation, device frames
```

The generated square was normalized to 1024×1024 before being copied into each Icon Composer
project. Platform-specific files are regenerated with `vp run icons:export`.
