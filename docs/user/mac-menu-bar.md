# Menu bar and tray

Solla Code keeps an icon in the macOS menu bar or the Windows tray while it is running. On a Mac it is a black and white bolt, with a number beside it counting the chats working right now.

Click the bolt on a Mac, or right-click the tray icon on Windows, for:

- how many chats are working, waiting on you, and [paused](./paused-threads.md), across every connected computer;
- how much memory and CPU the app is using, and how long it has been up;
- the chats themselves, so a click opens one;
- **Open Solla Code**, **Settings…**, and **Exit Solla Code**.

Closing the window only puts it away. Chats, terminals, and browser tabs keep running. On a Mac the bolt or the Dock icon brings the window back. On Windows, click the tray icon or open Solla Code again. Windows may tuck a new icon behind the **^** arrow beside the clock, and you can drag it out to keep it in view.

To really quit, choose **Exit Solla Code**, or press Cmd+Q on a Mac.
