# Mac menu bar

Solla Code keeps a black and white bolt in the macOS menu bar while it is running. A number beside it counts the chats working right now.

Click the bolt for:

- how many chats are working, waiting on you, and [paused](./paused-threads.md), across every connected computer;
- how much memory and CPU the app is using, and how long it has been up;
- the chats themselves, so a click opens one;
- **Open Solla Code**, **Settings…**, and **Exit Solla Code**.

Closing the window on a Mac only puts it away. Chats, terminals, and browser tabs keep running, and the bolt or the Dock icon brings the window back. To really quit, choose **Exit Solla Code** or press Cmd+Q.
