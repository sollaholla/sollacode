# Color themes

Settings → Appearance → **Theme** picks how Solla Code looks on web and desktop. You can also open the command palette and choose **Change theme…**; the current theme is marked there.

| Group        | Themes                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| Solla        | System (follows your computer's light or dark setting), Solla Light, Solla Dark                                  |
| Dark themes  | Dark High Contrast, Dracula, Nord, Monokai, One Dark, Solarized Dark, GitHub Dark, Tokyo Night, Catppuccin Mocha |
| Light themes | Light High Contrast, Solarized Light, GitHub Light, Catppuccin Latte                                             |

A named theme recolors the whole app: the sidebar, panels, menus, buttons, focus rings and the accent that Solla Dark draws in gold. It also changes:

- **Code and diffs.** Code blocks in chat, the diff panel, file previews and search results use the theme's own syntax colors (for example Dracula's).
- **The terminal.** The terminal uses the theme's 16 ANSI colors, with the cursor and selection in its accent.

Named themes don't follow the computer's light or dark setting. Pick **System** to go back to that.

The choice is saved per browser or desktop app, like the light/dark setting, and is applied before the first paint so the app doesn't flash Solla's colors while it loads. Every named theme keeps body text at 7:1 contrast or better (15:1 for the high-contrast themes), secondary text at 4.5:1, and button text at 4.5:1.

The mobile app follows the phone's light or dark setting and doesn't offer named themes yet.
