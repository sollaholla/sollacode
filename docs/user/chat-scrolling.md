# Reading while a response generates

The transcript follows new output while you are at the bottom. Scroll toward older messages to pause following. New text, images, and completed work then keep your reading position.

Expanding or collapsing a tool, a turn, a long message, or a file list also pauses following. The control you used stays in place as the content is measured. Changing table expansion or code wrapping behaves the same way.

Use **Scroll to end**, send a message, or scroll all the way to the bottom to follow new output again. Scrolling close to the bottom does not resume following early.

This behavior applies to the web client and the desktop apps that use it, including a web client connected to a remote environment.
